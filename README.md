# Daniel Nikoloski - Personal Website

Hi, this is a static site showcasing my work as a Senior Platform Engineer specializing in cloud infrastructure, Kubernetes orchestration, and GitOps workflows.

## 🚀 Quick Start

### With Docker Compose
```bash
podman-compose up --build --no-cache -d
```

Then navigate to `http://localhost:8000`

## 📋 Features

- Responsive design
- Accessibility (ARIA labels, semantic HTML)
- Social media links (X, GitHub, LinkedIn)
- Blog integration
- CV download
- Contact email

## 📝 Content

- **Blog**: Featured articles on topics like privacy infrastructure and Tor/Snowflake proxies
- **Background**: Professional experience with cloud infrastructure, DevOps, and security
- **Social Links**: Connections to GitHub, LinkedIn, X/Twitter, and encrypted contact methods
